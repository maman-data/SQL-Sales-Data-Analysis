# PROJECT 03: SQL SALES ANALYSIS

## 1. Project Overview
This project analyzes sales transaction data using MySQL and SQL queries. The objective is to understand sales performance, product performance, customer purchasing behavior, and order status.

## 2. Tools Used
- MySQL
- phpMyAdmin
- XAMPP
- SQL

## 3. Database Structure
This project contains four tables:

1. **customers** – Customer information.
2. **products** – Product information and prices.
3. **orders** – Order dates and statuses.
4. **order_details** – Product quantities and transaction details.

## 4. SQL Skills Applied
- SELECT
- WHERE
- BETWEEN
- JOIN
- GROUP BY
- ORDER BY
- HAVING
- COUNT()
- SUM()
- AVG()

## 5. Analysis Results
- Total Sales Value: Rp21,150,000
- Total Orders: 5
- Total Products Sold: 9 units
- Average Product Price: Rp2,190,000
- Best-Selling Product: Mouse Logitech
- Highest Revenue Product: Laptop Lenovo
- Highest Revenue Category: Electronics
- Top Customer: Andi Saputra

## 6. Business Insights
- Electronics generated the highest sales value.
- Laptop Lenovo contributed the largest product revenue.
- Mouse Logitech had the highest sales quantity.
- Andi Saputra was the highest-spending customer.
- Three orders were completed, one was pending, and one was processing.

## 7. Conclusion
This project demonstrates the use of SQL for data analysis, including database relationships, sales calculations, product performance, customer analysis, and business insights.
